Section 02 · Learning

The core of the product.

All three learning modules read from the same data/vocabulary.json (149 terms with English, 中文, pinyin, pronunciation guide, English example translation, definition, A/B/C answers, and category).

Glossary

/learning/glossary

The full 149-term directory. Sticky toolbar with search, status filter (All / Not yet / Learned), 9-category filter, and sort. Every filter state lives in the URL — links are shareable. Clicking a row opens a slide-in side panel with the full term detail.

  • Search across English, 中文, pinyin, definition, category
  • Side-panel detail (English ↔ 中文 ↔ pinyin ↔ pronunciation ↔ example)
  • Mark-as-learned · saved to localStorage
  • Keyboard: ↑↓ rows, Enter opens, Esc closes, ←→ in panel

Quiz

/quiz

A standalone 20-question round that mixes three question types at random — Setup → Play → Results, with instant feedback and a missed-words review that deep-links into the glossary. (The classic definition-matching quiz now lives under LEARN as Test your understanding at /learning/quiz.)

  • 填空 — fill the blanked term into a Chinese example sentence
  • 配对 — match a Chinese term to its English word or definition
  • 组字 — pick the missing character to complete a Chinese phrase
  • 20 random questions · 9-category filter · auto-marks correct as learned
  • Keyboard: 1 / 2 / 3 to choose · Enter to advance

Section 04 · Account

Sign up, sign in, dashboard.

Supabase auth via @supabase/ssr. Email confirmation required. The four /account/* pages are guarded — they redirect to /login when signed out, or show a friendly "Auth isn't configured yet" notice when env vars are missing.

Heads up on the next 5 screenshots

Today the project has no Supabase keys yet, so every /account/* route renders the placeholder "Auth isn't configured yet" panel. The page UIs themselves (Profile, Goals, Progress, Matching) are fully built — they unlock the moment .env.local is filled in. Optional · see it live

Three commands.
Two minutes.

If you want to click around an interactive version: install Node.js 18+ (nodejs.org), then run the commands at right. The site comes up at http://localhost:3000. 

# 1. Clone the repo
git clone https://github.com/North-South-Climate-Dialogue/nscd-web.git
cd nscd-web

# 2. Install dependencies (once)
npm install

# 3. Start the dev server
npm run dev
